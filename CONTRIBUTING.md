# Contributing

Contributions that improve detection accuracy, vendor coverage, defensive
telemetry, or reproducibility are welcome.

Please include:

- the exact Java runtime and vendor;
- CPU model and visible feature flags;
- whether `UseBASE64Intrinsics` was enabled;
- a negative control;
- commands and observed output from a clean clone.

Do not submit reverse shells, credential theft, public-target scanning, or
unverified claims of RCE.
